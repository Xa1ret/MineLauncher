Данные

Java

Каталог

Modrinth работает сразу. CurseForge тоже работает сам, если в лаунчер вшит ключ. Если ключа нет, вставь свой (бесплатно на console.curseforge.com).

Музыка

Добавь свои файлы (mp3, ogg, wav, m4a, flac), и они будут играть в лаунчере по кругу. Пока идёт игра, музыка ставится на паузу.
