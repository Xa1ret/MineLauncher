# MineLauncher

Лаунчер Minecraft со сборками, загрузчиками модов и каталогом. Ядро на **Rust**, окно на **Tauri**.
Готовый результат: обычная программа (.exe с установщиком), а не html-файл.

## Что умеет

- **Вход**: Ely.by или лицензия Microsoft (режима «просто офлайн» нет). Скины аккаунта подтягиваются сами.
- **Сборки**: у каждой своя версия игры, свой загрузчик и свои моды, они не мешают друг другу.
  Загрузчики: Vanilla, Fabric, Quilt, Forge, NeoForge.
- **Управление содержимым**: моды (включить, выключить, удалить), ресурспаки, шейдеры, миры. Копия сборки, память и аргументы Java на каждую сборку, время игры.
- **Каталог** из Modrinth и CurseForge: моды, ресурспаки, шейдеры, датапаки, миры. Зависимости модов ставятся сами.
- **Готовые сборки** других людей: установка в один клик (Modrinth .mrpack и CurseForge), а также импорт из файла.
- **Java**: нужная версия скачивается сама (8, 17, 21, 25) или свой путь.
- **Темы**: Тёмная, Красная, Пепел, Призрак, Жидкое стекло и аниме-темы (Сакура, Неон-Токио, Звёздная ночь, Матча, Кавай, Закат), свой цвет акцента.
- **Внешний вид**: Манга, Мягкий, Плоский, Пиксель. Скругление, прозрачность и размытие панелей, компактный режим, меню справа, пресеты.
- **Кастомизация**: эффекты (пепел, дождь, сакура, звёзды, сердечки, искры, линии), иероглиф на фоне, свои обои и персонаж-картинка (в том числе аниме), цвет акцента из картинки.
- **Эффекты**: количество и скорость частиц, смена страниц, свечение, след за курсором, парящий персонаж, виньетка, строки монитора, зерно.
- **Экран и шрифт**: масштаб интерфейса, размер окна, размер окна игры, шрифты, свой шрифт из файла.
- **Быстрый запуск**: закреплённые сборки и выбор, что делает лаунчер после старта игры (закрыться, свернуться, остаться).
- **Режим разработчика**: DevTools, свой CSS, журнал команд, экспорт настроек. Палитра команд на Ctrl+K.

## Запуск

```bash
cargo install tauri-cli --version "^2"
cargo tauri icon C:\main\icon.png
cargo tauri dev        # проверить
cargo tauri build      # установщик (.exe / .msi) в target\release\bundle
```

Нужны Rust, Visual Studio Build Tools (C++) и WebView2. Java ставить не нужно.

## Автообновление без своего сервера

Обновления раздаёт бесплатный GitHub (Releases), свой сервер не нужен. GitHub работает и в Украине, и в России.
Один раз:
1. Зарегистрируйтесь на github.com, создайте публичный репозиторий `MineLauncher` и загрузите туда папку проекта.
2. В папке проекта: `cargo tauri signer generate -w C:\main\minelauncher.key` (придумайте пароль). Команда выдаст **публичный ключ**.
3. Откройте `tauri.conf.json`: вместо `ВСТАВЬТЕ_ПУБЛИЧНЫЙ_КЛЮЧ…` впишите публичный ключ, а `YOUR_NAME` замените на ваш ник GitHub.
4. В репозитории: Settings → Secrets and variables → Actions → создайте секреты `TAURI_SIGNING_PRIVATE_KEY` (содержимое файла minelauncher.key) и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` (пароль).
5. Первый установщик соберите у себя (`cargo tauri build`), раздайте игрокам. Приватный ключ никому не показывайте.

Каждое обновление: поднимите `version` в `tauri.conf.json` и `Cargo.toml`, затем создайте тег (`git tag v0.4.1` и `git push --tags`). GitHub сам соберёт, подпишет и выложит релиз.
У игроков лаунчер при запуске покажет окно «Доступно обновление» с кнопками «Отказаться» и «Обновить». Отказавшись, обновиться можно в Настройки → Обновления.

## Ключ CurseForge

Modrinth работает сразу. Для CurseForge нужен бесплатный ключ разработчика:
console.curseforge.com → зарегистрироваться → API Keys. Чтобы каталог CurseForge работал у игроков сам, впишите ключ один раз в `ui/app.js` в константу `DEFAULT_CF_KEY` перед сборкой. Иначе каждый вставляет свой в Настройки → Каталог.
Некоторые авторы запрещают скачивание вне сайта CurseForge, такие моды лаунчер поставить не сможет и скажет об этом.

## Вход по лицензии (Microsoft): нужен свой Client ID

1. portal.azure.com → «Регистрация приложений» → «Новая регистрация».
2. Типы учётных записей: «Только личные учётные записи Microsoft».
3. Authentication → «Разрешить общедоступные потоки клиента» (Allow public client flows).
4. Скопируйте «Идентификатор приложения (клиент)».
5. Mojang требует одобрения нового Client ID (форма https://aka.ms/mce-reviewappid). Пока одобрения нет, вход по лицензии возвращает отказ.
6. Впишите ID в `ui/app.js` в константу `DEFAULT_MS_CLIENT_ID` или в Настройки → Аккаунт.

## Вход через Ely.by

Работает сразу. Двухфакторная защита: пароль вводят как `пароль:код`.

## Где что лежит

Всё хранится в папке `.minelauncher` (в данных приложений). Сборки лежат в `.minelauncher/instances/<сборка>`.
Библиотеки, ресурсы игры и Java общие для всех сборок, поэтому место не тратится дважды.

## Структура проекта

```
src/main.rs        — общие функции, Java, окно, шрифты, картинки
src/game.rs        — запуск игры (с загрузчиками)
src/loaders.rs     — Fabric, Quilt, Forge, NeoForge
src/instances.rs   — сборки и их содержимое
src/catalog.rs     — Modrinth, CurseForge, готовые сборки
src/auth.rs        — Ely.by, Microsoft, скины, поиск Java
ui/                — внешний вид (index.html, style.css, app.js)
```

## Новое: моды, экспорт, серверы

- **Обновление модов** — Каталог → «Установлено» → «Проверить обновления». У каждой строки кнопка «Обновить», сверху «Обновить всё».
- **Экспорт сборки** — Сборки → открыть сборку → «Экспорт в файл для друга». Получится `.mrpack`, его можно импортировать в этом же лаунчере (или в Modrinth App / Prism).
- **Серверы** — отдельная вкладка: список, онлайн, игроки, кнопка «Играть» заходит на сервер сразу после запуска. Список можно отправить другу кодом («Скопировать список» / «Вставить список»).
  Статус сервера берётся с бесплатного сервиса api.mcsrvstat.us (отправляется только адрес сервера).
- «Друзья онлайн» без собственного сервера невозможны, поэтому вместо них обмен списками серверов.

## Linux

Релиз теперь содержит и версию для Linux: `.AppImage` (запускается на любом дистрибутиве: `chmod +x MineLauncher*.AppImage && ./MineLauncher*.AppImage`), `.deb` (Ubuntu/Debian/Mint) и `.rpm` (Fedora/openSUSE). Автообновление работает так же, как на Windows.
Ограничения: нужна 64-битная система x86_64 (Mojang не выдаёт свою Java для ARM-Linux, там нужно указать свою Java в настройках), а для запуска игры нужны обычные графические драйверы.
Для сборки самому: `sudo apt install libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf libssl-dev libxdo-dev`, затем `cargo tauri build`.
