# MineLauncher

Лаунчер Minecraft со сборками, загрузчиками модов и каталогом. Ядро на **Rust**, окно на **Tauri**


## Ключ CurseForge

Modrinth работает сразу. Для CurseForge нужен бесплатный ключ разработчика:
console.curseforge.com → зарегистрироваться → API Keys. Чтобы каталог CurseForge работал у игроков сам, впишите ключ один раз в `ui/app.js` в константу `DEFAULT_CF_KEY` перед сборкой. Иначе каждый вставляет свой в Настройки → Каталог.
Некоторые авторы запрещают скачивание вне сайта CurseForge, такие моды лаунчер поставить не сможет и скажет об этом.

## Вход по лицензии (Microsoft): нужен свой Client ID

1. portal.azure.com → «Регистрация приложений» → «Новая регистрация».
2. Типы учётных записей: «Только личные учётные записи Microsoft».
3. Authentication → «Разрешить общедоступные потоки клиента» (Allow public client flows).
4. Скопируйте «Идентификатор приложения (клиент)».
5. Mojang требует одобрения нового Client ID (форма https://aka.ms/mce-reviewappid). Пока одобрения нет, вход по лицензии возвращает отказ.
6. Впишите ID в `ui/app.js` в константу `DEFAULT_MS_CLIENT_ID` или в Настройки → Аккаунт.

Лаунчер Minecraft со сборками, модами, каталогом и красивым оформлением.
Работает на Windows и Linux, обновляется сам.

## Скачать

Открой раздел [**Releases**](../../releases/latest) и выбери файл:

- **Windows:** `MineLauncher_..._x64-setup.exe` (установщик)
- **Linux:** `.AppImage` (подходит почти везде), `.deb` (Ubuntu, Debian, Mint) или `.rpm` (Fedora, openSUSE)

В Linux для `.AppImage`: `chmod +x MineLauncher*.AppImage`, затем `./MineLauncher*.AppImage`.

## Что умеет

**Сборки**
- У каждой сборки своя версия игры, свой загрузчик (Vanilla, Fabric, Quilt, Forge, NeoForge) и свои моды.
- Смена версии игры и загрузчика прямо в сборке, с подбором модов под новую версию.
- Ускорение игры одной кнопкой (моды для FPS), ремонт сборки, копия, экспорт в файл для друга.
- Свои Java, память и аргументы запуска для каждой сборки.

**Моды и каталог**
- Каталог Modrinth и CurseForge: моды, ресурспаки, шейдеры, датапаки, миры.
- Зависимости ставятся сами, проверка конфликтов, обновление модов, профили модов.
- Готовые сборки в один клик, импорт из файла и из других лаунчеров.
- Редактор конфигов и просмотр логов и крашей.

**Игра и аккаунт**
- Вход через Ely.by или лицензию Microsoft, свои скины.
- Серверы со статусом, онлайном и кнопкой «Играть».
- Быстрый запуск, статистика времени игры, нужная Java скачивается сама.
- Если игра упала, лаунчер покажет текст ошибки, его можно скопировать или отправить помощнику.

**Оформление**
- 11 тем, 4 стиля (Манга, Мягкий, Плоский, Пиксель), эффекты, свои обои и персонаж.
- Музыка из твоих файлов, звуки нажатий, русский и английский язык, горячие клавиши.

## Обновления

Новую версию лаунчер находит сам и предлагает обновиться. Ничего скачивать вручную не нужно. Проверить можно в **Настройки → Обновления**.

## Где хранятся данные

Всё лежит в папке `.minelauncher` (в данных приложения). Библиотеки и Java общие для всех сборок, поэтому место не тратится дважды.

## Вход через Ely.by

Работает сразу. Если включена двухфакторная защита, пароль вводится как `пароль:код`.
