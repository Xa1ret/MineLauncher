# MineLauncher

Лаунчер Minecraft со сборками, загрузчиками модов и каталогом. Ядро на **Rust**, окно на **Tauri**.
Готовый результат: обычная программа (.exe с установщиком), а не html-файл.

## Что умеет

- **Вход**: Ely.by или лицензия Microsoft (режима «просто офлайн» нет). Скины аккаунта подтягиваются сами.
- **Сборки**: у каждой своя версия игры, свой загрузчик и свои моды, они не мешают друг другу.
  Загрузчики: Vanilla, Fabric, Quilt, Forge, NeoForge.
- **Управление содержимым**: моды (включить, выключить, удалить), ресурспаки, шейдеры, миры. Копия сборки, память и аргументы Java на каждую сборку, время игры.
- **Каталог** из Modrinth и CurseForge: моды, ресурспаки, шейдеры, датапаки, миры. Зависимости модов ставятся сами.
- **Готовые сборки** других людей: установка в один клик (Modrinth .mrpack и CurseForge), а также импорт из файла.
- **Java**: нужная версия скачивается сама (8, 17, 21, 25) или свой путь.
- **Темы**: Тёмная, Красная, Пепел, Призрак, Жидкое стекло и аниме-темы (Сакура, Неон-Токио, Звёздная ночь, Матча, Кавай, Закат), свой цвет акцента.
- **Внешний вид**: Манга, Мягкий, Плоский, Пиксель. Скругление, прозрачность и размытие панелей, компактный режим, меню справа, пресеты.
- **Кастомизация**: эффекты (пепел, дождь, сакура, звёзды, сердечки, искры, линии), иероглиф на фоне, свои обои и персонаж-картинка (в том числе аниме), цвет акцента из картинки.
- **Эффекты**: количество и скорость частиц, смена страниц, свечение, след за курсором, парящий персонаж, виньетка, строки монитора, зерно.
- **Экран и шрифт**: масштаб интерфейса, размер окна, размер окна игры, шрифты, свой шрифт из файла.
- **Быстрый запуск**: закреплённые сборки и выбор, что делает лаунчер после старта игры (закрыться, свернуться, остаться).
- **Режим разработчика**: DevTools, свой CSS, журнал команд, экспорт настроек. Палитра команд на Ctrl+K.

## Ключ CurseForge

Modrinth работает сразу. Для CurseForge нужен бесплатный ключ разработчика:
console.curseforge.com → зарегистрироваться → API Keys. Чтобы каталог CurseForge работал у игроков сам, впишите ключ один раз в `ui/app.js` в константу `DEFAULT_CF_KEY` перед сборкой. Иначе каждый вставляет свой в Настройки → Каталог.
Некоторые авторы запрещают скачивание вне сайта CurseForge, такие моды лаунчер поставить не сможет и скажет об этом.

## Вход по лицензии (Microsoft): нужен свой Client ID

1. portal.azure.com → «Регистрация приложений» → «Новая регистрация».
2. Типы учётных записей: «Только личные учётные записи Microsoft».
3. Authentication → «Разрешить общедоступные потоки клиента» (Allow public client flows).
4. Скопируйте «Идентификатор приложения (клиент)».
5. Mojang требует одобрения нового Client ID (форма https://aka.ms/mce-reviewappid). Пока одобрения нет, вход по лицензии возвращает отказ.
6. Впишите ID в `ui/app.js` в константу `DEFAULT_MS_CLIENT_ID` или в Настройки → Аккаунт.

## Вход через Ely.by

Работает сразу. Двухфакторная защита: пароль вводят как `пароль:код`.

## Где что лежит

Всё хранится в папке `.minelauncher` (в данных приложений). Сборки лежат в `.minelauncher/instances/<сборка>`.
Библиотеки, ресурсы игры и Java общие для всех сборок, поэтому место не тратится дважды.
